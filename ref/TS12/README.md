# Trainz Simulator 12

_Trainz Simulator 12_, aka _TS12_, is a product that shipped in the Trainz Simulator series and was released by N3V Games (formerly Auran).  
It was released 12<sup>th</sup> April 2011.

## TrainzUtil GameScript Documentation

The tool `TrainzUtil.exe` that shipped with _TS12_ had a `-d` switch for its `compile` subcommand that would output the compiler's documentation of the Auran Game Script Language.

```bat
TrainzUtil.exe compile -d > "TrainzUtil GameScript Documentation.txt"
```

The output of the command above is included in this folder for reference.

To the knowledge of this Author (@fredrikhr), later products in the Trainz Simulator series (e.g. _T:ANE_, _TRS2019_ and _TRS2022_) do not support the `-d` command-line switch.  
The command `TrainzUtil.exe help` also will not show the `-d` switch in its help text for the `compile` subcommand.

See also: [TrainzUtil Command Line Arguments](https://online.ts2009.com/mediaWiki/index.php/TrainzUtil#Command_Line_Arguments)
